# AI-Based Network Intrusion Detection System

This project implements a **Deep Learning based Network Intrusion Detection System (IDS)** that detects malicious network traffic using machine learning techniques.

## Features
- Deep Learning Intrusion Detection Model
- Flask Web Application
- Real-time prediction of network traffic
- Detects normal vs intrusion traffic
- Interactive web interface

## Technologies Used
- Python
- TensorFlow / Keras
- Scikit-learn
- Flask
- HTML / CSS

## Dataset
The model is trained using a network intrusion dataset containing 41 network traffic features.
